# ``PlayCover``

PlayCover installs and runs supported iOS applications on Apple silicon Macs.

## Overview

The host manages the application library, installation, signing, and settings. PlayTools is the companion runtime framework for adaptive windows, input mapping, and compatibility with iOS APIs.

See the [maintainer guide](https://github.com/Rengwang/PlayCover/blob/develop/docs/MAINTENANCE.md) for the paired workspace and testing workflow, and [performance review](https://github.com/Rengwang/PlayCover/blob/develop/docs/PERFORMANCE.md) for benchmark methodology and bounds.
